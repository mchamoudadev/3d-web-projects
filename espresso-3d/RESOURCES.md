# 9 Bar machine resources

config/timeline.ts defines chapter ranges and camera keyframes. components/Machine/Placeholder.tsx builds the machine geometry; useMachineParts.ts supplies the future fourteen-part GLB integration boundary. store/progress.ts holds deterministic scroll state. notes/verification.md records earlier checks and limitations.

No GLB, HDR, API or remote font service is required for Phase 1. Fonts are npm dependencies with their own licenses. Future cutaway/exploded/brewing assets, price and CTA remain to be supplied or implemented. Build caches and screenshots are excluded.
